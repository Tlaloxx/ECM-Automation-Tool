# ECM Automation Tool

A Python-based automation tool that uses **Selenium** and **PyAutoGUI** to perform repetitive tasks in the **Enterprise Complaint Manager (ECM)** system, such as placing notes and navigating the interface — saving time and reducing manual effort.

## 🛠️ How to Run

```bash
# 1. Clone the repository
git clone https://github.com/yourusername/ECM-Automation-Tool.git
cd ECM-Automation-Tool

# 2. Install dependencies
pip3 install -r requirements.txt

# 3. Run the script
python3 main.py
